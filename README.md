# Custom New Tab Page

A clean, fast, and customizable start page for your browser.

## 🎮 [Try it Live](https://custom-new-tab-page-eight.vercel.app/)

---

## 🚀 Quick Start

1. Open the [Live Demo](https://custom-new-tab-page-eight.vercel.app/).
2. Set it as your browser's custom new tab URL in your browser settings.

## ✨ Features

* **Instant Load:** Lightweight design with zero bloat for fast tab opening.
* **Responsive Layout:** Works smoothly across different screen sizes.
